个人创作 API

GPT Image 2.5、Seedance 2.5、百炼 Qwen TTS。接口地址、模型 ID 和密钥均可自行设置。

素材留在本机

无需 ArtCraft 账号，不下载 AI 模型。视频任务保留 ID，重启后可继续查询。

第一次使用：完整解压 ZIP，双击「LTaiQin Studio.exe」，在「API 设置」填写服务商密钥。画布与 3D 基础编辑无需密钥；生成使用你的服务商额度。
